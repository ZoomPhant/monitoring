# Query Syntax

----

ZoomPhant provides powerful query languages for both metrics and logs, enabling you to analyze and visualize your monitoring data effectively.

## Available Query Languages

### [Metrics Query Syntax](metrics/)

Learn how to query metric data using our Prometheus-compatible query language (PromQL). This includes:

- Basic metric queries and label filtering
- Time series aggregations and calculations
- Built-in functions for rate, increase, and statistical analysis
- Advanced features like vector matching and subqueries

### [Logs Query Syntax](logs/)

Discover how to search and analyze log data using our log query language. Features include:

- Full-text search and pattern matching
- Field extraction and filtering
- Log aggregations and statistics
- Time-based log analysis

----

Choose the appropriate query language based on your data type and analysis needs.
